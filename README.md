# Teaching-an-LLM-how-to-count

LLMs can struggle with seemingly simple tasks such as accurately counting specific letters in words, as they are primarily trained for language generation rather than precise symbolic reasoning.

This project explores fine-tuning an LLM to improve its accuracy on letter-counting tasks using **GRPO, LoRA, reward shaping, and prompt engineering**.

## Techniques

* GRPO
* LoRA
* Reward Shaping
* Prompt Engineering
* Few-shot Prompting
